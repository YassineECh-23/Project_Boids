\doxysubsection{Detailed Description}
Gestionnaire de persistance (Sauvegarde et Chargement). 

Cette classe utilitaire (méthodes statiques) permet de \+:
\begin{DoxyItemize}
\item Sauvegarder l\textquotesingle{}état actuel de la simulation (paramètres + boids) dans un fichier.
\item Charger une simulation depuis un fichier existant.
\item Lister les sauvegardes disponibles sur le disque. 
\end{DoxyItemize}
