\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T$>$\newline
class bd\+::\+Dynamic\+Array$<$ T $>$}

Classe template gérant un tableau dynamique générique. 

Cette classe imite le comportement de std\+::vector. Elle gère automatiquement l\textquotesingle{}allocation et la réallocation de mémoire lorsque des éléments sont ajoutés. Elle fournit un accès sécurisé aux éléments avec vérification des bornes.
