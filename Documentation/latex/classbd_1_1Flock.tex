\doxysubsection{Detailed Description}
Classe gérant un ensemble de boids (groupe/nuée). 

Le \mbox{\hyperlink{classbd_1_1Flock}{Flock}} est le conteneur principal des agents. Il est responsable de \+:
\begin{DoxyItemize}
\item Stocker tous les boids.
\item Les initialiser et les gérer (ajout, suppression).
\item Appliquer les règles de comportement à l\textquotesingle{}ensemble du groupe. 
\end{DoxyItemize}
