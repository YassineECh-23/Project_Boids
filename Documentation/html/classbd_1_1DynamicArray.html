Detailed Description

template<typename T>
class bd::DynamicArray< T >

Classe template gérant un tableau dynamique générique.

Cette classe imite le comportement de std::vector. Elle gère automatiquement l'allocation et la réallocation de mémoire lorsque des éléments sont ajoutés. Elle fournit un accès sécurisé aux éléments avec vérification des bornes.

Template Parameters
TLe type de données stockées dans le tableau.
