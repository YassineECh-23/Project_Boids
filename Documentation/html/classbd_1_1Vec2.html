Detailed Description

template<typename T>
class bd::Vec2< T >

Classe template représentant un vecteur mathématique 2D.

Cette classe générique est utilisée pour représenter des positions, des vitesses, des forces ou des dimensions. Elle fournit toutes les opérations vectorielles usuelles (addition, soustraction, produit scalaire, normalisation, etc.).

TLe type de données sous-jacent (ex: float, double, int).

Calcule la longueur au carré du vecteur (Magnitude²).

Cette méthode est plus performante que length() car elle évite le calcul coûteux de la racine carrée (sqrt). À utiliser pour les comparaisons de distances.
