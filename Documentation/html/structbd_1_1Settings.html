Detailed Description

Structure contenant tous les paramètres de configuration de la simulation.

Cette structure regroupe les constantes et variables qui influencent le comportement des boids, les limites de l'environnement, les poids des règles et l'état des extensions (obstacles, prédateurs). Elle est partagée entre le moteur de simulation et l'interface graphique.
